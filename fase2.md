# IMPLEMENTAR FASE 2 — TMDB

Antes de começar leia toda a documentação existente e examine o código atual.

Implementar a integração com a API do TMDB.

Criar:

* Retrofit;
* API service;
* DTOs;
* RemoteDataSource;
* mapeamento DTO → domínio;
* tratamento de erros;
* configuração da API key;
* construção correta das URLs de imagens;
* Repository.

Implementar inicialmente:

* busca de filmes;
* busca de séries;
* detalhes de filmes;
* detalhes de séries.

Não implemente ainda:

* histórico;
* favoritos;
* coleção;
* progresso de episódios.

Criar testes para:

* parsing das respostas;
* mapeamento;
* tratamento básico de erro.

A API key deve permanecer fora do código versionado.

Ao terminar:

* build;
* testes;
* documentação em /docs/TMDB.md;
* atualizar ROADMAP.md.

Informe quais endpoints do TMDB foram utilizados.
